# Factorio Blueprint Hub

**Factorio Blueprint Hub** is a web platform and a community library of blueprints for Factorio players. Our project is designed to make automation simpler and knowledge sharing more efficient. Build faster, share smarter!

The platform allows players to publish their setups, find ready-made solutions using a flexible tag system, rate other users' work, and leave comments.

---

## Core Features

**Community Library**
* Publish your own blueprints with screenshots, tags, and the blueprint string.
* Easily browse the latest community uploads right on the homepage.

**Smart Search & Filtering**
* Quick blueprint search by title and description.
* Filter posts using thematic tags (e.g., `#railway`, `#oil`, `#science`, `#concrete`).

**Authentication & Profiles**
* Full registration and login system.
* Secure password validation to protect user accounts.
* Personal dashboard to manage your published blueprints.

**Social Interaction**
* Ability to upvote/like your favorite blueprints.
* Review and comment system for discussing and improving setups.

## Installation (Local Setup)

To run this project locally, follow these steps:

### 1. Clone the repository
```bash
git clone https://github.com
cd factorio-blueprint-hub
```

### 2. Set up a virtual environment (for Python/Django)
```bash
python -m venv venv
# For Windows:
venv\Scripts\activate
# For Linux/macOS:
source venv/bin/activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Run migrations and start the server
```bash
python manage.py migrate
python manage.py runserver
```
Once done, open your browser and navigate to: `http://127.0.0`

## Instalacja (konfiguracja lokalna)

Aby uruchomić projekt lokalnie, wykonaj następujące kroki:

### 1. Sklonuj repozytorium
```bash
git clone https://github.com
cd factorio-blueprint-hub
```

### 2. Skonfiguruj środowisko wirtualne (dla Python/Django)
```bash
python -m venv venv
# Dla systemu Windows:
venv\Scripts\activate
# Dla systemów Linux/macOS:
source venv/bin/activate
```

### 3. Zainstaluj zależności
```bash
pip install -r requirements.txt
```

### 4. Wykonaj migracje i uruchom serwer
```bash
python manage.py migrate
python manage.py runserver
```

Po wykonaniu tych kroków otwórz przeglądarkę i przejdź pod lokalny adres: `http://127.0.0`
