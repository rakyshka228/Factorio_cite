# Factorio Blueprint Hub

**Factorio Blueprint Hub** is a web platform and a community library of blueprints for Factorio players. Our project is designed to make automation simpler and knowledge sharing more efficient. Build faster, share smarter!

The platform allows players to publish their setups, find ready-made solutions using a flexible tag system, rate other users' work, and leave comments.

---

## ➡️ Core Features

**Community Library**
* Publish your own blueprints with screenshots, tags, and the blueprint string.
* Easily browse the latest community uploads right on the homepage.

**Smart Search & Filtering**
* Quick blueprint search by title and description.
* Filter posts using thematic tags (e.g., `#railway`, `#oil`, `#science`, `#concrete`).

**Authentication & Profiles**
* Full registration and login system.
* Secure password validation to protect user accounts.
* Personal dashboard to manage your published blueprints.

**Social Interaction**
* Ability to upvote/like your favorite blueprints.
* Review and comment system for discussing and improving setups.

* **Frontend:** HTML5 / CSS3
* **Database:** SQLite

---

## ➡️ Installation (Local Setup)

To run this project locally, follow these steps:

### 1. Clone the repository
```bash
git clone https://github.com
cd factorio-blueprint-hub
```

### 2. Set up a virtual environment (for Python/Django)
```bash
python -m venv venv
# For Windows:
venv\Scripts\activate
# For Linux/macOS:
source venv/bin/activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Run migrations and start the server
```bash
python manage.py migrate
python manage.py runserver
```
Once done, open your browser and navigate to: `http://127.0.0`

##  Как запустить проект локально (Installation)

Для запуска проекта на локальном компьютере выполните следующие шаги:

### 1. Клонируйте репозиторий
```bash
git clone https://github.com
cd factorio-blueprint-hub
```

### 2. Настройте виртуальное окружение (для Python/Django)
```bash
python -m venv venv
# Для Windows:
venv\Scripts\activate
# Для Linux/macOS:
source venv/bin/activate
```

### 3. Установите зависимости
```bash
pip install -r requirements.txt
```

### 4. Выполните миграции и запустите сервер
```bash
python manage.py migrate
python manage.py runserver
```
После этого откройте в браузере локальный адрес: `http://127.0.0`

**Factorio Blueprint Hub** ist eine Webplattform und eine Community-Bibliothek für Blaupausen (Blueprints) für Factorio-Spieler. Unser Projekt wurde ins Leben gerufen, um die Automatisierung zu vereinfachen und den Erfahrungsaustausch effizienter zu gestalten. Schneller bauen, smarter teilen!

* Filtern von Beiträgen nach thematischen Tags (z. B. `#eisenbahn`, `#öl`, `#wissenschaft`, `#beton`).

**Authentifizierung & Profile**
* Vollständiges Registrierungs- und Anmeldesystem.
* Sichere Passwortvalidierung zum Schutz der Benutzerkonten.
* Persönlicher Bereich zur Verwaltung der eigenen Veröffentlichungen.

**Soziale Interaktion**
* Möglichkeit, favorisierte Blaupausen zu liken.
* Bewertungs- und Kommentarsystem zur Diskussion und Verbesserung von Setups.
