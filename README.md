# Factorio Blueprint Hub

**Factorio Blueprint Hub** is a web platform and a community library of blueprints for Factorio players. Our project is designed to make automation simpler and knowledge sharing more efficient. Build faster, share smarter!

The platform allows players to publish their setups, find ready-made solutions using a flexible tag system, rate other users' work, and leave comments.

---

## Core Features

**Community Library**
* Publish your own blueprints with screenshots, tags, and the blueprint string.
* Easily browse the latest community uploads right on the homepage.

**Smart Search & Filtering**
* Quick blueprint search by title and description.
* Filter posts using thematic tags (e.g., `#railway`, `#oil`, `#science`, `#concrete`).

**Authentication & Profiles**
* Full registration and login system.
* Secure password validation to protect user accounts.
* Personal dashboard to manage your published blueprints.

**Social Interaction**
* Ability to upvote/like your favorite blueprints.
* Review and comment system for discussing and improving setups.

## Installation (Local Setup)

To run this project locally, follow these steps:

### 1. Clone the repository
```bash
git clone https://github.com
cd factorio-blueprint-hub
```

### 2. Set up a virtual environment (for Python/Django)
```bash
python -m venv venv
# For Windows:
venv\Scripts\activate
# For Linux/macOS:
source venv/bin/activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Run migrations and start the server
```bash
python manage.py migrate
python manage.py runserver
```
Once done, open your browser and navigate to: `http://127.0.0`

#  Factorio Blueprint Hub

**Factorio Blueprint Hub** — это веб-платформа и общественная библиотека рабочих чертежей (blueprints) для игроков Factorio. Наш проект создан для того, чтобы автоматизация стала проще, а обмен опытом — эффективнее. Стройте быстрее, делитесь умнее!

Платформа позволяет игрокам публиковать свои схемы, находить готовые решения через гибкую систему тегов, оценивать чужие работы и оставлять к ним комментарии.

##  Основные возможности (Features)

 **Общественная библиотека**
* Публикация собственных чертежей со скриншотами, тегами и строкой кода блупринта.
* Удобный просмотр свежих публикаций от сообщества прямо на главной странице.

 **Умный поиск и фильтрация**
* Быстрый поиск чертежей по названию и описанию.
* Фильтрация публикаций по тематическим тегам (например: `#железная_дорога`, `#нефть`, `#наука`, `#бетон`).

 **Авторизация и профили**
* Полноценная система регистрации и входа в аккаунт.
* Безопасная валидация паролей для защиты учетных записей пользователей.
* Личный кабинет для управления своими публикациями.

 **Социальное взаимодействие**
* Возможность ставить лайки понравившимся чертежам.
* Система отзывов и комментариев для обсуждения и улучшения схем.

# Factorio Blueprint Hub

**Factorio Blueprint Hub** ist eine Webplattform und eine Community-Bibliothek für Baupläne (Blueprints) für Factorio-Spieler. Unser Projekt soll die Automatisierung vereinfachen und den Wissensaustausch effizienter gestalten. Baue schneller, teile cleverer!

Die Plattform ermöglicht es Spielern, ihre Konstruktionen zu veröffentlichen, mithilfe eines flexiblen Tagsystems fertige Lösungen zu finden, die Arbeiten anderer Nutzer zu bewerten und Kommentare zu hinterlassen.

---

## Hauptfunktionen

**Community-Bibliothek**
* Veröffentliche eigene Baupläne mit Screenshots, Tags und dem Blueprint-String.
* Durchsuche bequem die neuesten Uploads der Community direkt auf der Startseite.

**Intelligente Suche und Filterung**
* Schnelle Suche nach Bauplänen anhand von Titel und Beschreibung.
* Filtere Beiträge mithilfe thematischer Tags (z. B. `#railway`, `#oil`, `#science`, `#concrete`).

**Authentifizierung und Profile**
* Vollständiges Registrierungs- und Anmeldesystem.
* Sichere Passwortvalidierung zum Schutz der Benutzerkonten.
* Persönliches Dashboard zur Verwaltung der veröffentlichten Baupläne.

**Soziale Interaktion**
* Möglichkeit, die Lieblingsbaupläne mit Upvotes oder Likes zu bewerten.
* Bewertungs- und Kommentarsystem zur Diskussion und Verbesserung von Konstruktionen.
